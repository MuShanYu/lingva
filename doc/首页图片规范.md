# 首页图片规范

首页每一块截图的建议尺寸。尺寸按页面实际布局算出：内容区最宽 1104px（`max-w-6xl` 1152px 减去左右各 24px 内边距），桌面端（≥1024px，Tailwind `lg`）各块的显示宽度见下表。

## 通用规则

1. **按 2 倍图提供**：图片宽度至少是「最大显示宽度 × 2」，高分屏（Mac、大多数笔记本和手机）上才清晰。表里的「建议尺寸」已经按 2 倍算好。
2. **截图条件一致**：浅色主题；浏览器缩放 100%；尽量在 2 倍屏上截，或者把浏览器缩放调到 200% 再截。这样各张图里的文字大小差不多。
3. **会被裁切的图**（表中「显示方式」为「固定框，裁切」）：图片按比例铺满固定大小的框，超出的部分被裁掉。主体内容要放在锚点附近，四周留出余量。
4. **格式与体积**：界面截图用 PNG，单张不超过 500KB，超出时先用 TinyPNG / oxipng 压缩。照片类内容（如漫画）可以改用 WebP。
5. **不出现个人信息**：不要露出 API Key、账号、邮箱、真实的浏览记录。漫画、视频这类第三方内容只截能公开展示的部分。
6. **换图时保持比例**：替换同一块的图片时按表中比例截取，不要改代码去迁就图片。如果确实需要改比例，同时更新这份文档。

各块的补充说明：

- **Overview 总览卡片**：缩略图在不同屏宽下的比例从 2.4:1 变到 3.3:1，只有中间一条一定能看到。可以单独截一张 2.5:1 的缩略图，也可以复用大图并用 `position` 指定锚点；两种方式都要把主体放在中间约 70% 的宽度内。
- **Video**：右栏是平台列表和字幕设置卡片，图片高度跟随右栏，左右两侧可能被裁掉，字幕和画面主体要居中。手机上图片单独一行，按原比例显示。
